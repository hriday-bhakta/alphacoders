Collaborative repository for coursework, practice programs, and shared discussions.

Hierachy:
common/ => used for all common discussions, programs and collabs
users/username => where you create your own files and assignments

# Workflow Rules
1. Work directly inside your personal directory under `users/`.
2. Do not modify or delete files inside someone else's user folder.
3. Always run `git pull origin main` before making new commits to avoid sync issues.
